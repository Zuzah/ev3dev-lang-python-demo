# SNATCH3R

IR remote-controlled claw robot for ev3dev2. Based on the SNATCH3R design from *The LEGO Mindstorms EV3 Discovery Book* by Laurens Valk.

## Controls (IR Remote)

| Button | Action |
|---|---|
| Top-Left + Top-Right | Move forward |
| Bottom-Left + Bottom-Right | Move backward |
| Top-Right | Turn right |
| Top-Left | Turn left |
| Bottom-Right | Open claw |
| Bottom-Left | Close claw |

## Channels = Speed

| Channel | Speed |
|---|---|
| 1 | 50% |
| 2 | 75% |
| 3 | 100% |
| 4 | Stop program |
